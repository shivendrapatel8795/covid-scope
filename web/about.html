About CovidScope

COVID-19 Data Visualization & Analysis

CovidScope transforms raw COVID-19 datasets into clear, meaningful visual insights. It demonstrates the complete data-analysis workflow — loading, cleaning, feature engineering, exploratory analysis and professional visualisation — using the Python data-science stack.

What this project does

  • Cleans and merges cases, deaths and vaccination records
  • Computes derived metrics (new cases, rolling averages, case-fatality rate)
  • Ranks countries and detects peak periods
  • Produces 10 high-quality charts for trends, comparisons and correlations
  • Presents everything in a clean, modern medical-tech UI

Tech Stack

Python
Pandas
NumPy
Matplotlib
Seaborn
HTML / CSS
Jupyter

How to run the analysis

From the project root: 

python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python src/analysis.py

Charts are written to the visualizations/ folder. Open web/index.html in a browser to view this UI.
